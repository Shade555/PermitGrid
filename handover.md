# PermitGrid - Project Handover

## Project Overview
PermitGrid is an AI-powered industrial approval, compliance & government services platform. 
It aims to simplify the complex process businesses face when starting, expanding, and operating an industrial unit.

## Tech Stack
*   **Frontend**: Next.js (App Router), React, TypeScript, Tailwind CSS
*   **UI Libraries**: shadcn/ui, Framer Motion, Recharts, Lucide React
*   **Backend**: Python, FastAPI, Pydantic (Planned)
*   **Database**: Supabase, PostgreSQL, pgvector (Planned)
*   **AI**: LLaMA 3 / OpenAI-compatible architecture, Sentence Transformers (Planned)
